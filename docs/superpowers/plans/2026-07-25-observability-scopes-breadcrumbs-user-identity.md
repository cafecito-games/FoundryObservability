# Observability Scopes, Breadcrumbs, and User Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add provider-neutral session and per-event scope, explicit user identity, and bounded typed breadcrumbs with complete Sentry Apple and Android mappings.

**Architecture:** Add immutable/copying FoundryScript DTOs and an optional provider capability for provider-owned session scope. The core validates and delegates global mutations, while per-event scope travels on `ObservabilityEvent`; the Sentry provider mirrors complete global scope snapshots into native SDK scope and applies event-local tags and contexts through capture-local callbacks.

**Tech Stack:** FoundryScript, Foundry testlib, Swift 6/XCTest, Sentry Cocoa 9.23.0, Java 17/JUnit, Sentry Android 8.50.1, Bash contract tests, Task.

---
